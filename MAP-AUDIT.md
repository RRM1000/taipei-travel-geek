# Custom Google My Maps embeds

Audited 2026-08-10. **56 embeds across 42 posts**, using 53 distinct maps.

Names come from each map's own metadata, so they are whatever the map is titled in Google My Maps.

## Status

**The pins in every map were reviewed and brought up to date on 2026-08-10.** Treat this file as a reference for which post uses which map, not as a to-do list.

Map **names** were reviewed at the same time and mostly left as they are, including the three walking routes whose titles are full sentences. They are not errors — they just read oddly out of context. The one exception is `tamsui`, renamed from "Danshui" to "Tamsui".

Note that Google serves map metadata from a cache, so a rename can take a while to show up. At the time of writing the `tamsui` embed still returned the old name. That affects link previews only, not the map itself.

**What this file can and cannot tell you.** Every map loads; none have been deleted or made private, re-checked after the update. But the embeds are cross-origin, so the pins inside them cannot be read from here — this file can confirm a map exists and what it is called, never whether its contents are current. The "post updated" column is only a hint at where content and pins may drift apart in future.
